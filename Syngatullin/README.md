# Training Planner

**Автор:** Сунгатуллин Султат

**Описание:**
Простое десктопное приложение для планирования и отслеживания тренировок. Позволяет добавлять новые записи, фильтровать их по типу и дате, а также сохранять данные в локальный файл JSON.

**Технологии:**
*   Python 3.x
*   Tkinter (стандартная библиотека)
*   JSON

**Примеры использования:**
1.  Запустите `main.py`.
2.  Введите дату (например, `29.04.2026`), тип тренировки (например, `Кардио`) и длительность (например, `45`).
3.  Нажмите «Добавить тренировку». Запись появится в таблице.
4.  Используйте фильтры для поиска нужных тренировок.
5.  Данные сохраняются автоматически при закрытии программы и загружаются при запуске.
